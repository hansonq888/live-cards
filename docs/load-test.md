# Load test

One server process (uvicorn, one worker) on a laptop, AI calls off. Every viewer is a WebSocket with its own live session: its own engine, auto-director and replay clock. Each level holds its viewers for 15 s after a 2 s warm-up. Server CPU is measured over the window (100% = one core). Generated by `backend/scripts/load_test.py`.

| Viewers | Connected | Real-time ratio (median / worst) | Frame gap p50 / p95 / p99 | Frames per viewer per s | Server CPU |
|---|---|---|---|---|---|
| 50 | 50 | 0.999 / 0.993 | 54.1 / 56.3 / 57.1 ms | 18.6 | 13.1% |
| 100 | 100 | 0.997 / 0.991 | 53.0 / 55.6 / 58.9 ms | 18.9 | 22.7% |
| 200 | 200 | 0.993 / 0.98 | 55.3 / 102.7 / 144.9 ms | 16.4 | 66.0% |
| 400 | 339 | 0.993 / 0.977 | 57.7 / 151.0 / 246.4 ms | 12.9 | 97.4% |

A real-time ratio of 1.00 means the match plays at true speed for that viewer; below 1 the server can no longer keep every session's clock up.
